# Компоненты и лицензии

Перед коммерческим выпуском юридически проверьте каждую фактически скачанную ревизию.

* Собственный код этого репозитория: см. `LICENSE` (MIT).
* [Chatterbox code](https://github.com/resemble-ai/chatterbox): MIT по upstream; веса — отдельно по model card/download metadata, проверка ожидается.
* [FastAPI](https://github.com/fastapi/fastapi), [Uvicorn](https://github.com/encode/uvicorn), [NumPy](https://github.com/numpy/numpy), [SoundFile](https://github.com/bastibe/python-soundfile): permissive/BSD-лицензии upstream.
* [PyTorch](https://github.com/pytorch/pytorch): BSD-style; [FFmpeg](https://ffmpeg.org/legal.html): конкретная сборка может быть LGPL/GPL в зависимости от опций.
* [Caddy](https://github.com/caddyserver/caddy): Apache-2.0; официальный container image.
* MOSS, Qwen, RUAccent, OpenVoice и Silero **не входят** в runtime; их ссылки в исследовании не означают поставку или лицензионное одобрение.
