# Приёмка

## Обязательные требования

| Требование | Статус | Доказательство / ожидающая проверка |
|---|---|---|
| Zero-shot индивидуальное клонирование | **не проверено** | Реализована передача пользовательского WAV как `audio_prompt_path`, без fallback и обучения. Нужны два референса и слепая оценка результата на VM. |
| Полноценная русская речь и 10 000+ знаков | **не проверено** | `language_id="ru"`, lossless segmentation и автотест сохранности текста реализованы; реальный длинный WAV и прослушивание ожидаются. |
| Ручное управляемое ударение в аудио | **не проверено** | Оба синтаксиса, валидация, приоритет и преобразование в `+` покрыты тестом. Влияние на **аудио** нужно прослушать по 20 формам; разность input не считается успехом. |

Следовательно, проект пока **не прошёл обязательную аудиоприёмку**. Причина — в среде не загружались веса, отсутствуют Docker и пользовательский референс; ни один пункт не помечен успешным без WAV/прослушивания.

## Чек-лист на VM

- [ ] Дважды выполнить `sudo bash ./install.sh`; сверить сохранность профиля и health после reboot.
- [ ] Создать профиль из WAV, MP3, M4A и WebM; проверить тишину и повреждённый файл.
- [ ] Получить настоящий WAV/MP3 без сети/API/GPU; затем отключить WAN и повторить после `HF_HUB_OFFLINE=1` и restart.
- [ ] Прослушать 20 форм из `tests/stress-corpus.txt`, отдельно варианты `+` и U+0301, seeds 0/1/2.
- [ ] Синтезировать одинаковую фразу двумя голосами; убедиться, что пути/результаты не смешаны.
- [ ] Проверить сказку, стих, спокойное чтение колыбельной. Пение не реализовано и не заявляется.
- [ ] Проверить текст ≥10 000 символов, порядок, окончания, паузы и отсутствие щелчков.
- [ ] Отмена во время сегмента; restart во время генерации; отсутствие весов/места/памяти.

## Форма слуховой оценки

Для каждого файла запишите: ID/seed; ожидаемое ударение; услышанное ударение (верно/неверно/неясно); сходство 1–5; естественность 1–5; пропуски/добавления; артефакты/щелчки; комментарий. Оценщик не должен видеть вариант пары. Метрики ASR и speaker embedding — только вспомогательные.
