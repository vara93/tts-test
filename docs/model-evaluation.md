Не переносим возможности Turbo/Nano на Multilingual и CustomVoice/VoiceDesign на Base. RUAccent не включён, пока не проверены его лицензия, pinned-модель и сохранение ручных знаков. OpenVoice/Silero не выбраны: составной тракт требует отдельной проверки сходства и сохранения ударений.

## Воспроизводимый эксперимент на целевой VM

1. Установить сервис; создать один профиль из принадлежащей пользователю записи.
2. Положить `tests/stress-corpus.txt` в редактор, сделать задания с seed 0/1/2 (seed задаётся по индексу сегмента; для отдельных повторов используйте benchmark script).
3. Запустить `docker compose exec worker python benchmark_cpu.py /data/profiles/1/reference.wav --runs 3`.
4. Записать холодную загрузку, preparation, synthesis, длительность, RTF, peak RSS в `docs/cpu-benchmark.md`.
5. Прослушать все пары вслепую по форме acceptance. Разные токены и ASR не считать подтверждением ударения.

До выполнения этих шагов сходство, естественность и коммерческая допустимость checkpoint имеют статус «не проверено».
