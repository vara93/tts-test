# «Своя интонация» — локальная студия клонирования голоса

CPU-first веб-приложение для русской озвучки с zero-shot референсом. Основной движок — **Chatterbox Multilingual 0.1.6**; стандартный голос при ошибке никогда не подставляется. Исходный и подготовленный тексты сохраняются раздельно в SQLite, а тяжёлая генерация выполняется отдельным последовательным worker.

> Важный статус: код и быстрые тесты проверены в среде разработки, но веса (сеть недоступна), реальный CPU-синтез и слуховая оценка **не проверены**. До прохождения `docs/acceptance.md` проект нельзя считать прошедшим обязательную приёмку или сравнивать по качеству с ElevenLabs.

## Установка

На Ubuntu x86_64:

```bash
git clone <адрес> voice-studio && cd voice-studio
sudo bash ./install.sh
```

Скрипт не меняет системный Python: ставит Docker из репозитория фактической Ubuntu, печатает ресурсы/CPU flags, проверяет сеть и порты, собирает зафиксированный образ, загружает модель, создаёт настоящий `data/install-smoke.wav` на CPU и проверяет health endpoint. Smoke проверяет загрузку и русский синтез стандартного condition, но не доказывает клонирование; cloning проверяется с вашим профилем. `.env`, данные и модели сохраняются между повторами. Пароль будет напечатан один раз и останется в `.env` (режим 600). Порты и имя задаются до запуска: `STUDIO_HOST=172.22.111.82 HTTPS_PORT=443 sudo -E bash ./install.sh`.

В checkpoint Chatterbox 0.1.6 встречаются CUDA-tagged tensor storage. Приложение при загрузке модели принудительно передаёт `map_location=cpu`, поэтому установка на машине без CUDA не падает с `Attempting to deserialize object on a CUDA device`. После успешного smoke-теста установщик переключает `HF_HUB_OFFLINE=1`; web и worker больше не обращаются к Hugging Face.

## Первый запуск и запись

Откройте напечатанный HTTPS-адрес, нажмите «Войти», затем запишите 10–30 секунд (допустимо 3–60) без музыки, эха и других голосов. Можно загрузить WAV/MP3/M4A/WebM; FFmpeg преобразует его в mono 24 kHz. Тишина, клиппинг, повреждённый файл и размер свыше 100 MB отклоняются. Шумоподавление специально не применяется. Рекомендуемый текст:

> Сегодня тихий вечер. Я читаю этот текст спокойно, отчётливо и естественно. За окном шумят деревья, а в комнате тепло и уютно.

После сохранения выберите профиль, режим, введите текст и запустите задачу. Абзацы не удаляются, текст до 100 000 знаков режется по фразам, прогресс равен числу реально готовых частей. Worker продолжает работу без вкладки; после аварийного перезапуска активная задача получает ошибку, а не ложный вечный прогресс. На CPU одновременно работает одна задача.

## Ударения

Поддерживаются `за́мок` (U+0301 после гласной) и `з+амок` (`+` перед гласной). Кнопка работает для конкретной позиции. Приоритет: ручная отметка конкретного вхождения → пользовательский словарь → неизменённый текст. Автоакцентуация пока намеренно отключена: непроверенный RUAccent не должен перетирать ручную разметку. В Chatterbox передаётся формат `+`; неверная позиция отклоняется до очереди.

## HTTPS и микрофон

Caddy создаёт локальный CA и сертификат для фактического `STUDIO_HOST`. Скопируйте `data/caddy/pki/authorities/local/root.crt` **на клиентский ПК** и импортируйте в доверенные корневые сертификаты ОС/браузера. Сертификат на сервере сам по себе не делает клиент доверяющим. Готовые сертификаты можно подключить, заменив `tls internal` в `Caddyfile` на `tls /путь/fullchain.pem /путь/key.pem` и смонтировав файлы read-only. Закрытый ключ не коммитьте.

Для теста без установки CA: `ssh -L 8000:localhost:80 user@172.22.111.82`, затем `http://localhost:8000` (localhost считается secure context). Загрузка файла работает и без разрешения микрофона.

## Обслуживание

```bash
sudo bash ./doctor.sh
docker compose logs -f worker
docker compose restart
docker compose down                 # данные не удаляются
docker compose build --pull         # только явное обновление образа
```

Резервируйте `data/`, `.env` и при необходимости `models/`. Удаление профиля удаляет его референс; связанные завершённые результаты также удаляются из БД (каталог результатов администратор может очистить по политике хранения). Не публикуйте `.env`, `data`, `models`, CA private key или записи.

## Проверки

```bash
python -m pytest -q
bash -n install.sh doctor.sh
docker compose config
docker compose exec worker python benchmark_cpu.py /data/profiles/1/reference.wav
```
